# personal website!

my personal website. built using sveltekit! it features a list of my projects, a photo gallery for my photography, a background grid of photos, and contact info. it paginates the photo gallery. it uses the github api when pulling projects. it also pulls photos from my r2 bucket.

this is probably like the most thought i've put into css.

i do want to add a recently playing section, but i haven't gotten around to that part yet.

lives on [https://kangaroos.dev](https://kangaroos.dev).

## ai declaration

ai was used to do a good part of the background grid and the code generated by AI is marked with comments stating so. it also made the entire svelte.config.js and github actions workflow. the rest of the code was written by me :D
